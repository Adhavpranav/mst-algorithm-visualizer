# MST Algorithm Visualizer

This is a web-based project to visualize and understand Minimum Spanning Tree (MST) algorithms, mainly Prim's and Kruskal's algorithms.

## About the Project

The project allows users to enter the number of vertices and weighted edges of a graph. The aim is to make learning MST algorithms easier through a simple interface.

## Features

- Enter the number of vertices.
- Enter weighted edges manually.
- Validate graph input.
- Load sample graph data.
- Simple and responsive user interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- jQuery

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
